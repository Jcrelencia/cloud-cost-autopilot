## 🎯 Project Overview

Cloud Cost Autopilot is a backend system that connects to AWS accounts, scans EC2 instances, and identifies cost-saving opportunities by detecting idle or underutilized resources.

**The Problem:** Small businesses lack time and expertise to monitor cloud spending, resulting in wasted money on idle resources.

**The Solution:** Automated scanning that identifies waste and generates actionable recommendations with estimated dollar savings.

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **AWS Integration:** AWS SDK (EC2, CloudWatch, STS)
- **Cloud Services:** IAM roles, temporary credentials, CloudWatch metrics
